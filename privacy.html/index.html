Privacy Policy

Application: auto · Last updated: 24 October 2026

auto is a content-publishing tool for creators. It connects to the user's own TikTok account through TikTok's official APIs in order to upload video files that the user produces.

1. What this application does

The application authenticates with TikTok using OAuth, receives an access token for the user's account, and uploads video files to that same account. It does not create accounts for third parties.

2. Data we process

  • TikTok OAuth tokens (access and refresh tokens), stored locally on the user's own computer.
  • Video files produced by the user, stored locally until uploaded.
  • Basic account information returned by TikTok (such as the account's display name and posting permissions), used only to confirm that publishing is allowed.

3. What we do not collect

  • We do not collect personal data from any TikTok user other than the user.
  • We do not use cookies, analytics, advertising identifiers, or tracking pixels.
  • We do not sell, rent, or share data with third parties.
  • We do not store passwords.

4. Third-party services

The application communicates only with TikTok's official API endpoints (open.tiktokapis.com and www.tiktok.com) and with the video source platforms the user chooses. Data handled by TikTok is governed by TikTok's own Privacy Policy.

5. Storage and security

Tokens and video files are stored on the user's local machine, protected by the operating system's user account. No cloud database is used by this application.

6. Retention and deletion

You can revoke this application's access at any time:

  • In TikTok: Settings and privacy → Security and permissions → Manage app permissions, then remove auto.
  • Locally: delete the token file on the user's machine.

Once access is revoked, the tokens become invalid and no further uploads can occur.

To request deletion of any data associated with this application, contact alanborin14@gmail.com. Requests are handled within 30 days.

7. Children

This application is not directed to children and is not intended for use by minors.

This policy may be updated to reflect changes in the application. The revision date at the top of this page will always indicate the current version.
